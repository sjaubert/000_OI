\begin{tcolorbox}[boite]\textbf{Le but.} Saisir des valeurs à la main, coller un tableau, corriger une erreur.\par\textbf{Il vous faut.} Le projet créé en E1 · La page « Données à copier »\end{tcolorbox}
\begin{tcolorbox}[pred]On tape 11,87 avec une virgule, puis 11.87 avec un point. Ellistat va-t-il accepter les deux ?\reponse\end{tcolorbox}
\titre{À faire}
\begin{enumerate}[label=\textcolor{cyan}{\textbf{\arabic*.}},leftmargin=15pt,itemsep=1.5pt]
\item \tagE\ Dans la première colonne de la grille, taper : 11,87 puis Entrée, 11,86 puis Entrée, 11.84 puis Entrée. Observer ce qu'affiche chaque case.
\item \tagE\ Corriger une case : cliquer dessus et retaper. Annuler avec Ctrl + Z, rétablir avec Ctrl + Y.
\item \tagE\ Clic droit sur une case : essayer \menu{Ajouter une ligne après}, puis \menu{Supprimer la ligne}.
\item \tagW\ Ouvrir la page « Données à copier », jeu « 30 butées en une colonne ». Choisir le séparateur qui a fonctionné, puis cliquer sur « Copier le tableau ».
\item \tagE\ Créer une \menu{Nouvelle grille} (sélecteur de grille), cliquer dans la première case, coller avec Ctrl + V.
\item \tagE\ Vérifier : 30 lignes, une colonne « Diametre ».
\end{enumerate}
\titre{J'observe, je décide}
\begin{enumerate}[label=\textcolor{cyan}{\textbf{Q\arabic*.}},leftmargin=22pt]
\item Quel séparateur décimal votre grille accepte-t-elle : la virgule, le point, les deux ?\reponse[1]
\item Un import par \menu{Importer depuis Excel} crée toujours une nouvelle grille. Comment ajouter des lignes à une grille qui existe déjà ?\reponse[1]
\item Pourquoi vérifier le nombre de lignes après chaque collage ou import ?\reponse[1]
\end{enumerate}
\begin{tcolorbox}[retenir]La grille se comporte comme un tableur : on saisit, on colle, on annule. On contrôle toujours ce qui est entré avant de calculer.\end{tcolorbox}
